The chat

Claude Code, beside the paper

The chat is a Claude Code session on your laptop, in the library: the same skills, tools and notes as in VS Code or the terminal. The tablet only shows it.
It carries on through a reload or a sleeping tablet. Go back to any earlier chat in the library, including the ones from VS Code or the terminal.
Slash commands: /overview, /add-paper, /literature-review and the rest of the library's skills.
A line under the chat says how long the prompt cache has left, and your usage limits.
You decide. Anything beyond reading is put to you as Allow or Deny.
